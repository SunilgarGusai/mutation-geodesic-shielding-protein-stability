# Third-party data and software terms

The MIT License in this repository applies to original repository code authored for this project. It does **not** relicense third-party datasets, structures, statistical potentials, publications, or software.

## Tsuboyama mega-scale stability resource

Tsuboyama et al., *Mega-scale experimental analysis of protein folding stability in biology and design*, Nature (2023).  
DOI: https://doi.org/10.1038/s41586-023-06328-6

The public repository does not mirror the large raw source dataset. Users should obtain the source material from the original resource and comply with its source terms.

## FireProt / ThermoMPNN benchmark resource

Dieckhaus et al., *Transfer learning to leverage larger datasets for improved prediction of protein stability changes*, PNAS (2024).  
DOI: https://doi.org/10.1073/pnas.2314853121  
Associated dataset record: https://zenodo.org/records/8169289

The manuscript uses a frozen PDB-mapped external benchmark after sequence decontamination and mapping. Raw source files are not relicensed here.

## Ssym experimental WT/mutant structures

Pucci et al., *Quantification of biases in predictions of protein stability changes upon mutations*, Bioinformatics (2018).  
DOI: https://doi.org/10.1093/bioinformatics/bty348

Experimental coordinate files remain subject to their original database/source terms.

## MJ96 residue-pair statistical potential

Miyazawa and Jernigan, *Residue-residue potentials with a favorable contact pair term and an unfavorable high packing density term, for simulation and threading*, Journal of Molecular Biology (1996).  
DOI: https://doi.org/10.1006/jmbi.1996.0114

The published statistical-potential table is not reprinted in this repository. The public code expects an audited external table when that component is used.

This repository depends on NumPy, SciPy, pandas, matplotlib, and pytest. Each package retains its own license and copyright terms.

Before redistributing any downloaded dataset, coordinate archive, potential table, or third-party software artifact, consult the originating project's current license/terms. Nothing in this repository should be interpreted as granting rights over third-party material.
