# Frozen result tables

These CSV files contain the aggregate values used by the manuscript and quantitative figures.

- `cohort_summary.csv`: cohort sizes and scientific roles.
- `main_results.csv`: principal target-free, external, and structural estimates.
- `mgsc_characterization.csv`: development shielding prevalence and exact-agreement audit.
- `predictive_added_value.csv`: grouped added-information comparison against the direct baseline.
- `external_validation.csv`: independent site-level, adjusted-specificity, and same-site estimates.
- `structural_credibility.csv`: descriptive virtual-versus-explicit structure summaries.
- `structural_radius_robustness.csv`: radius-wise structural comparison summaries.
- `structural_cluster_class_counts.csv`: class counts by experimental structural cluster.
- `parent_origin_shielding_prevalence.csv`: descriptive natural/de novo prevalence.
- `gate_summary.csv`: compact record of supported, unsupported, and inconclusive comparisons.
- `claim_register.csv`: machine-readable interpretation/claim boundary.

The external benchmark is closed to further hypothesis search; these files document frozen results rather than a tuning surface.
