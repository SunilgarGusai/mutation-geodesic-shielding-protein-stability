# Reproducibility and audit policy

## Frozen scientific state

The public repository reflects the final scientific state of the study. Failed predictive analyses remain failed; no public-release editing step is allowed to retune radii, endpoints, models, subsets, or external hypotheses.

## Public artifacts

The repository contains:

- MGSC reference equations and implementation;
- target-free mathematical/implementation tests;
- machine-readable headline result tables;
- provenance and claim-boundary documentation;
- final manuscript and figures after editorial QA.

## Author-side archive

The larger author-side archive retains downloaded structures, source snapshots, mapping audits, homology-group assignments, full per-mutation feature tables, out-of-fold predictions, bootstrap outputs, logs, hashes, and one-click Windows execution packages.

Those large or third-party materials are not all appropriate for direct redistribution. The public repository therefore supports transparent audit of the published claims and a compact implementation of the central method, while provenance files identify the original public sources.

## No hidden rescue analysis

The original local-VELE predictive route and the later GS3 added-value prediction test produced negative primary results. These remain part of the paper. The independent external benchmark was used once under a frozen multilevel analysis protocol and is not reused for post-hoc feature or subgroup search.
